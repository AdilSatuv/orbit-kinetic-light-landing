# ORBIT / kinetic light

Учебный концепт светового объекта: Next.js, React, SCSS, Framer Motion, Three.js. Бренд и изделие вымышлены; работа создана совместно с AI-ассистентом.

`npm ci`, `npm run dev`, `npm test`, `npm run build`.

Статический экспорт в `out`; Cloudflare Pages: команда `npm run build`, ветка `main`, каталог `out`.

`lib/config.js` проверяет параметры, восстанавливает ссылку и создаёт текст описания. `lib/scene.js` содержит процедурную геометрию, материалы, управление и жизненный цикл WebGL. `Viewer` загружает сцену по явному действию; `Experience` хранит единое состояние. При ошибке WebGL остаются SVG и настройки. Автовращение выключено по умолчанию; offscreen, hidden tab и reduced motion останавливают цикл. Все ресурсы освобождаются. Физическая точность света не заявляется.

Текущая публикация использует Cloudflare Pages Direct Upload: https://adil-orbit-light.pages.dev/. Push запускает GitHub CI, но не автоматическую публикацию этого нового проекта. Для обновления собрать out и загрузить его содержимое в Pages. Git-интеграция исходных пяти проектов сохранена.
